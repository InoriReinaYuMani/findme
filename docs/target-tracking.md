# 接近ナビの確認

## 今回の範囲

参加者の選択、直線距離、近づいている／遠ざかっている／ほぼ同じ距離の表示を追加。
GPS精度不足・古い位置・未取得は断定せず、更新待ちとして表示する。
方向案内、移動経路、バックグラウンド追跡、通知、サーバー接続は含まない。

## 自動テスト

`swift test` で距離、接近・離反、誤差、短間隔更新、更新停止、対象切替、欠損、
古い位置・逆順更新、日付変更線、旧データのデコード互換性を確認する。
PRの既存CIでSwiftLint・Swift package tests・iOS Simulator向けビルドを実行する。

## Xcodeでの確認

1. `xcodegen generate` でプロジェクトを更新する。
2. `TargetTrackingView` のPreviewで420mのカードを確認する。
3. ルーム参加後、相手がいなければ対象選択の案内が表示され、自分は選択肢に含まれないこと。
4. VoiceOver、大きい文字、iPhone SEサイズ、横向きで対象選択と退出が操作できること。
5. 位置権限を拒否・取り消ししたとき、エラーがルーム画面にも出て接近判定が消えること。

## バックエンド接続後の実機2台テスト（未実施）

現在の `InMemoryRoomStore` だけでは2台の通信はできない。
`RoomStore` のサーバー実装を `RoomViewModel(store:)` に渡してから以下を実施する。

| 操作 | 期待結果 |
| --- | --- |
| 相手を選択 | 距離カード表示、地図の対象がオレンジ色 |
| 自分または相手が十分移動 | 5秒以上の間隔で接近／離反を表示 |
| 両者が止まる | 誤差内の変化では接近／離反を断定しない |
| 自分は静止し相手だけ移動 | 2秒ごとの取得で距離が更新される |
| 相手または自分の更新が止まる | 30秒超で距離を隠し更新待ち |
| 対象を変更・解除 | 前の相手の距離比較を引き継がない |
| 対象が退出してストアから削除 | 選択とカードが解除される |
| 退出直後に通信が完了 | 古いルームの参加者・距離が画面に復活しない |
| 同じルームに再参加 | 新しい位置が届くまで接近を断定しない |

## 公開までに残る既存の課題

- サーバー、ルーム参加の認可、参加者削除・期限切れ、明示的な共有ON/OFF。
- 現在のアプリは参加時に位置共有を要求する。今回その同意フローの再設計は行っていない。
- バックグラウンド復帰・ネットワーク遅延・実GPSでのしきい値調整。
- TestFlight、プライバシー申告、App Store素材と審査。

位置の精度と取得日時は `CLLocation` の元データを維持する。
参考: https://developer.apple.com/documentation/corelocation/cllocation/horizontalaccuracy
